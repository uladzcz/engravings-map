# Карта гістарычных гравюр і панарам (Engravings Map)

Інтэрактыўная вэб-карта для геаграфічнай прывязкі і каталагізацыі старадаўніх гравюр, планаў і панарам гарадоў XVI–XVIII стагоддзяў (у тым ліку земляў Беларусі / ВКЛ і суседніх рэгіёнаў).

### Асаблівасці праекта
* **Развянчанне міфаў і псеўда-выяваў:** адрознівае аўтэнтычныя віды горада ад памылковых («псеўда-Магілёў», «псеўда-Гродна») і барочных кампіляцый.
* **Візуальная сувязь «заяўленае &harr; рэальнае»:** на карце пункцірнай лініяй злучаецца заяўленае месца (напрыклад, Магілёў ці Гродна) з рэальным архітэктурным прататыпам (напрыклад, замак Гюстраў у Мекленбургу ці замак Гродна ў Сілезіі).
* **Фільтрацыя:** па стагоддзях (XVI, XVII, XVIII ст.), тыпе праўдзівасці (аўтэнтычныя / памылковыя / кампіляцыі) і пошук па аўтарах і гарадах.
* **Прамыя спасылкі на Вікісховішча (Wikimedia Commons):** высокая раздзяляльнасць і першакрыніцы.
* **Працуе без сервернай часткі:** чысты кліенцкі код (Leaflet.js + HTML5/CSS), гатовы да бясплатнай публікацыі праз **GitHub Pages**.

## Як разгарнуць на GitHub Pages за 2 хвіліны

1. Стварыце новы публічны рэпазіторый на [GitHub](https://github.com) (напрыклад, `engravings-map`).
2. Ініцыялізуйце і адпраўце файлы з гэтай тэчкі:
   ```bash
   git init
   git add .
   git commit -m "Першапачатковы рэліз карты гравюр"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НІК/engravings-map.git
   git push -u origin main
   ```
3. У наладах рэпазіторыя на GitHub:
   * Перайдзіце ў **Settings** &rarr; **Pages**.
   * У раздзеле **Build and deployment** абярыце галіну `main` і тэчку `/ (root)`.
   * Націсніце **Save**.
4. Праз хвіліну ваша інтэрактыўная карта стане даступнай па адрасе:
   `https://ВАШ_НІК.github.io/engravings-map/`

## Аўтаматычны імпарт цэлых альбомаў з Вікісховішча

У тэчцы `scripts/` ёсць утыліта:
```bash
python scripts/fetch_commons_album.py "Curioses Staats und Kriegs Theatrum in Polen (1730)"
```
Яна спампуе спіс усіх аркушаў з абранай катэгорыі, выцягне аўтарства, даты і выявы, і падрыхтуе файл `extracted_plates.json`, з якога зручна пераносіць каардынаты гарадоў у асноўную базу.
